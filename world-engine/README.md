# World Engine —— 把「真沙盒」接进 ElecKoi

这是一个 DSH Host 插件（ElecKoi 的插件中心可以直接安装），给角色扮演流程加一层**代码判定的世界状态机**。

当前版本只内置一个世界：

> **德意志帝国 · 2025（总集版）** —— 依据《德意志帝国 · 世界观与人物设定总集》生成。
> 旧版《黄昏档案》的卡、预设与世界数据已从本机删除。

## 它解决什么

没有引擎时，世界的时间、NPC 在不在场、事件该不该发生，全靠模型自觉，玩久了就会漂移。
装上它之后：

- **世界时间**按分钟推进，由代码维护，模型不能随便跳时间；
- **NPC 日程**是数据：每个 NPC 一天里什么时候在哪、在做什么，由引擎算，模型查得到；
- **触发器**是硬判定：到点必然发生（城市宫御前晚宴、禁军换岗、维什戴尔抵达柏林、情报局简报、布达佩斯晚宴、华沙授勋），变量到阈值必然发生（封锁、东翼军演、莫斯科集会、伊利里亚遇袭、黑光泄露、记者围堵等）；
- **暗线**按 tick 节奏推进阶段，只产出「机会/伏笔」，不强迫玩家；
- **世界变量**有上下限和档位，越界会被裁剪；
- **骰子**按规则裁定（1d20 + 调整 − 难度 → 大失败/失败/部分成功/成功/大成功）；
- **关键 NPC 决策**：根据目标、日程、世界变量、玩家行动关键词，给出独立决定意图；
- **玩家不在场的事件**单独标记为「场外事件」，只能通过转述/新闻/伏笔起作用，不能写成玩家亲眼所见。

状态按**会话**持久化，重开对话继续；不同角色会话互不干扰。

## 提供的工具

| 工具 | 作用 |
| --- | --- |
| `world_state` | 读取权威状态：时间、地点、在场人物及活动、可去地点、变量、暗线、状态行 |
| `world_init` | 初始化/重置世界；可选 `worldId`、`playerName`、`location`、`locationName`、`startTime` |
| `world_tick` | 推进分钟数：NPC 移动、到点事件、阈值事件、暗线、城中传闻 |
| `world_move` | 移动到相邻地点、自由场景或从自由场景回到已知地点；校验出口/扣路上时间/沿途推进世界 |
| `world_npc` | 查询 NPC：身份、现在在哪/在做什么、目标、关系、知道什么、日程 |
| `world_npc_act` | 让 NPC 基于目标/日程/变量/刺激做独立决定 |
| `world_apply` | 修改变量（增量、范围校验）与标记 |
| `world_dice` | 按规则掷检定 |
| `world_plots` | 查看暗线进度与最近推进 |
| `world_memory` | 外部剧情存档：把关键记要追加到 E 盘 Markdown，或读取/列出存档 |

## 内置世界

| worldId | 名称 | 内容 |
| --- | --- | --- |
| `deutsches-reich-canon`（默认） | 德意志帝国 · 2025（总集版） | 21 地点（柏林/波茨坦/维也纳/布达佩斯/华沙/莫斯科）、20 NPC、10 变量、15 触发器、6 条暗线 |

- 世界数据在 `worlds/*.json`，普通 JSON，按 `id` 区分；`default: true` 的那个是新会话的默认世界。
- `world_init` 传 `worldId` 可以选择世界；会话已经开始推进后切换世界必须传 `reset: true`。
- 配套预设的协议条目里已经写好了 `worldId`，通常不需要手动传。

### 自由场景（v1.3.0）

- 想开场在引擎地图之外的地方（伦敦、巴黎、自创房间），让模型调用
  `world_init { locationName: "伦敦·白金汉宫", ... }`：引擎以「自由场景」开局，状态卡地点显示该名称，时间/变量/暗线照常运转。
- 在自由场景里，用地 `world_move { locationName: "巴黎·一家小旅馆", minutes: 90 }` 切换；
  回已知地点用 `world_move { locationId: "berlin-stadtschloss", minutes: 300 }`（默认 180 分钟）。
- 自由场景没有固定出口与预设 NPC 站位；NPC 互动靠设定库、`world_npc` 与 `world_npc_act`。

### 外部剧情存档（v1.5.0）

- Windows 上存档默认写在 **E 盘**：`E:\DS Work Space\1\ElecKoi-德意志帝国-总集版\剧情存档\<会话编号>.memory.md`；Android 上默认写在 DSH 应用私有 profile 的 `world-engine/剧情存档/` 下。
- `world_memory { action:"save", chapter:"第 X 章 · 场景", text:"3–5 行关键事件、关系变化、未结线索" }` 追加记要；
  `{ action:"read" }` 读取当前会话存档；`{ action:"list" }` 列出所有存档文件。
- 存档不占上下文、不会因为对话变长而消失；你也能直接用记事本/Obsidian 打开 `.memory.md` 阅读或备份。
- 要用别的路径：设置环境变量 `WORLD_ENGINE_MEMORY_DIR`，或插件 config 的 `memoryDir`；Windows 不会静默改存 C 盘。

## Android / 手机端

- 插件本身是纯 JS、无原生依赖，可在 Android 版 ElecKoi 的插件中心安装；但本插件目前以本地 Windows 目录分发，手机无法直接读取这个目录。
- 要装到手机：把本目录上传成公开 GitHub 仓库，在手机插件中心输入 `github:用户名/仓库名`（若插件中心支持 GitHub 地址）；或发布到 npm 后按包名安装。
- Android 上的剧情存档默认在应用私有 profile 目录，不会写到 Windows 的 E 盘。

## 安装

1. ElecKoi → **插件中心 → 添加插件** → 选择本目录（本地目录安装）。
   若面板只接受包名，也可以把本目录路径告诉「创作工作室」的 Agent，让它安装本地插件。
2. 安装后确认插件已启用；工具会出现在「角色扮演预设 → 工具 → 额外工具」里。
3. 导入配套预设与角色卡（都在 `E:\DS Work Space\1\ElecKoi-德意志帝国-总集版\`）：
   - 角色卡：`德意志帝国-2025-总集版.character.json`
   - 预设：`德意志帝国-2025-总集版-世界引擎预设.preset.json`（角色扮演预设分类）
4. 新建对话，选择该预设 + 角色卡，按开场白选择世界视角。

## 注意

- 需要模型支持工具调用（DeepSeek 系模型都可以）。
- 每轮会多 1–3 次工具调用（读取状态、推进时间、查 NPC），首轮和多 NPC 场景会慢一点。
- 世界状态按 DSH 会话编号存到 profile 的 `world-engine/` 目录；删除该目录等于清空所有世界的推进记录。
- 这个插件只做「世界状态机」；叙述、文风、状态卡渲染仍由角色卡/预设负责。
