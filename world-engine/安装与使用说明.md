# World Engine 安装与使用说明

> 目标：把「德意志帝国」升级成**代码判定世界状态的开放世界沙盒**。
> 需要的三样东西：本插件目录、`ElecKoi-德意志帝国-总集版\` 里的角色卡、以及同一目录里的世界引擎预设。
> 当前只内置一个世界：**德意志帝国 · 2025（总集版）**（依据《德意志帝国 · 世界观与人物设定总集》）。
> 旧版《黄昏档案》的卡、预设与世界数据已删除。

---

## 0. 系统要求

| 项 | 要求 |
| --- | --- |
| 客户端 | ElecKoi 0.3.5 或更高（内置 DSH 0.2.2-rc.5；更高版本也兼容） |
| 模型 | 支持工具调用（tool calling）。DeepSeek 系模型都可以；纯聊天模型无法使用 |
| 平台 | Windows（插件是纯 JS，无原生依赖；Android 版是否支持本地插件目录安装以客户端实际为准） |

---

## 1. 安装/更新插件

1. 打开 ElecKoi → 左侧进入 **插件中心**。
2. 点 **添加插件**。安装对话框支持三种输入：npm 包名、GitHub 仓库地址、**本地目录路径**。
3. 在输入框里填本目录的绝对路径：

   ```
   E:\DS Work Space\1\ElecKoi-世界引擎插件
   ```

4. 安装成功后插件列表里会出现 **「世界引擎（开放世界沙盒）」**，确认它是**启用**状态、版本为 **1.5.0**。
5. **完全退出并重启 ElecKoi**，让插件加载新的世界数据（如果之前装过旧版，也靠这次重启换掉）。
6. 如果提示「需要重启」，重启 ElecKoi 后再继续。

> 安装方式是「本地目录」链接：以后修改本目录里的文件，重启客户端即可生效。
> 如果插件中心无法安装本地目录，也可以在 **创作工作室** 里对 Agent 说：
> 「把本地插件目录 `E:\DS Work Space\1\ElecKoi-世界引擎插件` 安装到当前 profile 并启用」，
> 或让 Agent 用 DSH 插件管理工具安装。

---

## 2. 导入角色卡与世界引擎预设

1. 角色库 → **导入角色卡** → 选择：
   `E:\DS Work Space\1\ElecKoi-德意志帝国-总集版\德意志帝国-2025-总集版.character.json`
2. 预设 → **角色扮演预设**（必须在这个分类里导入，否则会提示用途不符）→ **导入** → 选择：
   `E:\DS Work Space\1\ElecKoi-德意志帝国-总集版\德意志帝国-2025-总集版-世界引擎预设.preset.json`
3. 打开导入后的预设 **「德意志帝国 · 2025 总集版 · 世界引擎预设」** → **工具** 页，确认：
   - 内置工具里有 **设定库**、**变量**；
   - **预设工具** 里有 10 个 `world_*` 工具（世界状态、初始化世界、推进时间、移动地点、查询 NPC、NPC 自主决策、修改世界变量、掷骰检定、查看暗线、剧情存档）。
   - 如果某个 `world_*` 显示缺失：插件没安装/没启用，或需要重启客户端；也可以点「管理预设工具」手动把插件的工具加进来。
4. 选中该预设（设为当前角色扮演预设）。

## 3. 开一局真沙盒

1. 角色库选中 **「德意志帝国 · 2025（总集版）」**。
2. 新建对话 → 选一个开场白：
   - **柏林 · 冯·马肯森基地的早晨（主开场）**：扮演皇储威尔海姆（开局 2025-03-15 09:30）
   - **布达佩斯 · 格德勒宫的午间休息**：扮演维什戴尔（开局 2025-03-15 11:00）
   - **柏林 · 情报局的下午茶**：扮演夏洛特（开局 2025-03-15 15:00）
   - 也可以**不用开场白**，直接打一段自定义场景（见下面的「自由场景开局」）。
3. 第一轮：模型应调用 `world_state`；未初始化时会调用
   `world_init {worldId:"deutsches-reich-canon", playerName:…, location:…, startTime:…}`，
   然后才开始叙述。如果自定义场景在引擎地图之外，会改用 `locationName` 而不是 `location`。
4. 之后每次行动，模型会按需调用 `world_tick`（时间推进）、`world_move`（移动/换场景）、`world_dice`（检定）、`world_apply`（变量后果）、`world_npc`（查人物）。

### 自由场景开局（v1.3.0）

如果想让开场发生在引擎地图之外的地方（伦敦、巴黎、华盛顿、自创房间），不需要改世界数据：

- 第一条消息写清楚：**扮演谁、什么时间、在哪里**，例如：
  > 我不使用开场白。我扮演一名在伦敦的外交随员，时间是 2025 年 11 月 22 日下午，地点在伦敦·白金汉宫。
- 模型会调用 `world_init { worldId:"deutsches-reich-canon", playerName:"…", locationName:"伦敦·白金汉宫", startTime:"2025-03-16T14:00" }`。
- 状态卡的地点会显示「伦敦·白金汉宫」，时间与世界变量照常推进。
- 在自由场景之间切换：`world_move { locationName:"巴黎·一家小旅馆", minutes:90 }`。
- 回到引擎地图：`world_move { locationId:"berlin-stadtschloss", minutes:300 }`（不写 minutes 默认 180 分钟）。
- 自由场景没有固定出口与预设 NPC 站位；NPC 互动靠设定库与 `world_npc` / `world_npc_act`。

### 外部剧情存档（v1.5.0）

- 存档在 Windows 上默认写在 **E 盘**：`E:\DS Work Space\1\ElecKoi-德意志帝国-总集版\剧情存档\<会话编号>.memory.md`；Android 上默认写在 DSH 应用私有 profile 的 `world-engine/剧情存档/`。
- 保存：`world_memory { action:"save", chapter:"第 X 章 · 场景", text:"3–5 行关键事件、关系变化、未结线索" }`；读取：`{ action:"read" }`；列出：`{ action:"list" }`。
- 卡脚本里有「剧情存档」按钮，点一下会让模型读取并存档展示；你也可以直接用记事本打开该目录里的 `.memory.md`。
- 想换路径：设置环境变量 `WORLD_ENGINE_MEMORY_DIR`，或插件 config 的 `memoryDir`；Windows 下不会静默改存到 C 盘。

### 自检清单（第一局）

- [ ] 第一轮可见工具调用里有 `world_state` / `world_init`
- [ ] `world_init` 参数里 `worldId=deutsches-reich-canon`
- [ ] 状态卡的日期/时间/地点/在场与引擎返回的「状态行」一致
- [ ] 主开场 09:30 在冯·马肯森基地；推进到 03-16 08:00 会触发禁军换岗、10:00 维什戴尔抵达柏林、15:00 情报局简报
- [ ] 03-16 08:00 有禁军换岗、10:00 维什戴尔抵达柏林、15:00 情报局简报
- [ ] 柏林 ↔ 维也纳/布达佩斯/华沙/莫斯科的移动会被扣掉火车时间
- [ ] 如果自定义了地图之外的开场：`world_init` 里有 `locationName`，状态卡地点显示该名称
- [ ] 做一个有风险的动作：出现 `world_dice`，结果按大失败/失败/部分成功/成功/大成功叙述
- [ ] 做一件改变局势的事：出现 `world_apply`，变量变化能在 `world_state` 里看到
- [ ] `world_plots` 能看到罗曼诺夫公投、伊利里亚、双冠传闻、不列颠暗流、黑光、双柱裂痕

任何一项不满足，先看下面的排错。

## 4. 排错

| 现象 | 原因 / 处理 |
| --- | --- |
| 插件中心装不上、提示不是插件包 | 必须选**本目录**（含 `package.json`、`cordis.patch.yml`、`index.js`），不是选 JSON 文件 |
| 插件列表没有「世界引擎」 | 安装未完成或需要重启；到 插件中心 → 已安装 里找，确认启用 |
| 插件行显示「异常 / 包不可用」 | 插件管理器读不到包信息。先点插件中心的**刷新**；仍不行就**重启 ElecKoi**；再不行则卸载后重新添加本目录。维护提示：`package.json` 必须是**无 BOM 的 UTF-8** |
| 预设工具页看不到 `world_*` | 插件没启用；或先在插件中心启用后重启；再回到预设工具页刷新 |
| 预设提示用途不符 | 必须在「角色扮演预设」分类里导入 |
| 第一轮不调用 `world_state` | 模型不支持工具调用；或预设未选中；或工具页里 `world_*` 被停用。可在第一条消息写「（请先调用 world_state）」验证 |
| 工具报「缺少会话编号」 | 世界引擎只能在角色会话里用，不能在工作台/创作会话里用 |
| 工具报「没有这个世界数据」 | 插件还是旧版，或 `worldId` 写错。当前可用：`deutsches-reich-canon`；重启 ElecKoi 后重试 |
| 工具报「没有这个地点」 | 想在地图之外开场时不要传 `location`，改传 `locationName:"伦敦·白金汉宫"`；从自由场景回地图用 `world_move { locationId, minutes }` |
| 工具报「切换世界需要 reset=true」 | 同一会话已推进过世界，换世界必须 `reset=true`；也可以直接新建对话 |
| 世界状态错乱/想重开 | 让模型调用 `world_init` 并传 `reset=true`；或删掉状态文件（见下） |
| 工具报 `Cannot find package '@deepseek-ai/dsh-tools'` | 插件被当成普通 npm 包安装了，必须通过 ElecKoi 插件中心作为 DSH 插件安装 |

状态文件位置：

```
%APPDATA%\eleckoi-desktop\dsh-runtime\home\profiles\desktop\world-engine\<会话编号>.json
```

删掉对应文件 = 清空那一局的世界状态（不会删除聊天记录）。

## 5. 想换成自己的世界？

`worlds/deutsches-reich-canon.json` 就是世界数据（`worlds/` 下每个 `*.json` 都会加载，按 `id` 区分，`default: true` 为新会话默认世界）。结构：

```jsonc
{
  "id": "deutsches-reich-canon",
  "title": "德意志帝国 · 2025（总集版）",
  "worldDate": "2025-03-15",       // 世界起始日期
  "startTime": "2025-03-15T18:30", // 起始时刻
  "player": { "name": "威尔海姆", "startLocation": "charlottenburg-palace" },
  "locations": [ { "id": "...", "name": "...", "exits": [ { "to": "...", "minutes": 10 } ] } ],
  "npcs": [ { "id": "...", "home": "...", "schedule": [ { "from": 480, "to": 720, "location": "...", "activity": "..." } ], "goals": [ ... ] } ],
  "startPlacements": { "charlotte": { "location": "...", "activity": "..." } },
  "variables": [ { "key": "alert_level", "min": 0, "max": 5, "default": 2, "bands": [ ... ] } ],
  "dice": { "defaultDifficulty": 10, "checks": [ ... ] },
  "triggers": [ { "id": "...", "at": "2025-03-15T20:00", "text": "...", "visibility": "public", "effects": { ... } } ],
  "plots": [ { "id": "...", "steps": [ { "text": "..." } ], "intervalTicks": 4 } ]
}
```

- 时间 `from/to` 是一天里的分钟数（480 = 08:00）。
- `visibility`：`public`、`location:<地点 id>`、`npc:<人物 id>`、`offscreen`。
- 改完 JSON 后重启 ElecKoi；已有会话的世界状态仍按旧会话文件保留，重开新对话或 `world_init reset=true` 才会用新数据。
- 想加新世界：复制一份 JSON，改 `id`/`title` 与内容放进 `worlds/`，预设协议里把 `world_init` 的 `worldId` 换成新 id 即可；不需要改插件代码。

## 6. 卸载/回滚

1. 插件中心 → 已安装 → 停用或卸载「世界引擎」。
2. 预设可以继续用，但 `world_*` 会显示缺失、模型不会调用；建议同时切回「默认扮演预设」。
3. 角色卡不受影响：没有引擎时它仍按卡内的普通规则工作（卡里写了无引擎时的回退规则）。
